# Mandaxpress

A lightweight point-of-sale (POS) system for events, based on the Mandaladaka project.

## Features (planned)

- Quick sales and manual amount entry
- Cash, card, and Pix payment tracking
- Open tabs and deferred payments
- Prepaid credits and balance management
- Cash register reconciliation

## Status

Under development.

**First use case:** Festival do Açaí — October 31, 2026.
